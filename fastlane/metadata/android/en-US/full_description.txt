<p><i>Note Calendar</i>is a customizable offline app which allows you to manage notes for each day and offers a way to quickly reach for each of them. App does not contain ads.</p><p><br><b>Features</b></p><ul><li>Day screen - used to add, edit or delete note and set a reminder for it.</li><li>Month screen and week screen<ul><li>Days that constain a note are marked with a ring.</li><li>The currently selected day is marked with a solid circlee.</li><li>Today's date is marked with a different text color</li><li>Long-press a day’s number to quickly add or edit a note for that day.</li><li>A find button that allows to search notes by text, with optional case-sensitive and date-range filters.</li></ul></li><li>Settings screen<ul><li>Notes - notes-specific settings, including options to import and export notes.</li><li>Calendar - calendar-specific settings, such as the first day of the week.</li><li>Theme - choose a light or dark theme, create your own theme, and export it.</li><li>About - information about the application.</li></ul></li></ul>
